# 🏠 خانه موبایل (Khane Mobile)

سایت فروشگاهی نمونه برای نمایش گوشی‌های مختلف با طراحی واکنش‌گرا و رابط کاربری زیبا.  
این پروژه به عنوان نمونه‌کار شخصی طراحی شده است.

## 📱 ویژگی‌ها
- نمایش محصولات برندهای مختلف (Samsung, Xiaomi, iPhone)
- صفحه‌ی سبد خرید با JavaScript
- طراحی واکنش‌گرا (Responsive)
- ساختار فولدر حرفه‌ای و مرتب

## 💻 تکنولوژی‌ها
- HTML5
- CSS3
- JavaScript
